1. 浏览器打开 https://arxiv.org/register — 注册 arXiv 账号（可用 ORCID 关联）
2. 登录后 → Start New Submission
3. 上传 D5-033_arxiv_submission.tar.gz
4. 选择类别：Mathematics → Number Theory (math.NT)
5. 填写元数据（标题、摘要、作者）

7. 确认并提交 → 获取 arXiv ID (e.g., 2406.XXXXX)
