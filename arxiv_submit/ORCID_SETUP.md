# ORCID Setup for MSS Publications

## Step 1: Register (2 min)
1. Go to https://orcid.org/register
2. Fill: First name, Last name, Email, Password
3. Verify email → Get ORCID (e.g., 0000-0002-1825-0097)

## Step 2: Link to Zenodo (1 min)
1. Go to https://zenodo.org/account/settings/applications/
2. Click "Connect" next to ORCID
3. Authorize Zenodo → ORCID

## Step 3: Add to preprint (1 min)
1. Go to https://zenodo.org/records/20537026
2. Edit → Authors → Add your name + ORCID
3. Save

## Step 4: Add to GitHub README (optional)
Add ORCID badge:
```markdown
[![ORCID](https://img.shields.io/badge/ORCID-0000--0002--XXXX--XXXX-a6ce39)](https://orcid.org/0000-0002-XXXX-XXXX)
```

## Why
- Permanent researcher identity (survives name changes, affiliation changes)
- Zenodo auto-syncs publications to ORCID profile
- Required by most academic journals
- Free, takes <5 minutes
