# Δ 写入权奠基：为什么"所有提案者共享合法 R-修改方向"不是一个可假设的前提

> "如果写入权的前提是错觉，整个 Δ 协议可能已被绕过。"
> — DEBT-02

## 问题定位

Δ 协议当前定义的核心操作：

1. τ 窗口打开 → 任何提案者可提交 R-修改
2. 提案进入逻辑交集 → 取所有提案的公共部分
3. Δ 更新 → 框架蜕壳

**隐含前提（从未显式奠基）**：所有提案者共享一个合法的 R-修改方向。

如果这个前提不成立，逻辑交集要么是空的，要么是某个被伪装成共识的权力决策。

## 第一部分：为什么这不是一个可假设的前提

### 1.1 戈多式等待

"所有提案者共享合法方向"是一个——借用贝克特——永远在路上但永远不会到达的假设。它假设：

- 存在一个"合法方向"的集合
- 这个集合可以被所有理性提案者识别
- 识别后他们会自然涌入这个方向

这三步每一步都可独立失败：

| 假设 | 失败方式 |
|------|---------|
| 存在合法方向集合 | 框架可能处于多个不等价合法方向的岔路口 |
| 可被所有理性提案者识别 | 识别依赖共享认知架构，但提案者可能来自不同范式 |
| 识别后自然涌入 | 提案者有独立动机（reputation, priority, bias） |

### 1.2 罗尔斯式遮蔽

如果"合法方向"被某个人或某个判断过程预先定义，逻辑交集就退化为"和那个人一致的方向"。

这不是逻辑交集，这是审查。

### 1.3 阿罗不可能性定理的影子

从阿罗不可能定理（Arrow, 1951）可知：不存在能把个体偏好排序加总为社会偏好排序的投票规则，同时满足一组自然公理。

翻译到 Δ 写入权：

- 提案者 = 选民
- R-修改方向 = 偏好排序
- 逻辑交集 = 加总规则

**结论**：逻辑交集做不到"民主概括"——要么它是有序的（被一个裁决者定义的），要么它是空的。

## 第二部分：奠基方案

不接受"共享合法方向"的假设，而是从下列三条中选一条奠基。

### 方案 A：最小承诺交集（推荐）

**定义**：逻辑交集不一定非空。如果交集为空，Δ 不更新。框架保持当前状态，记录分歧但不选边。

**优势**：
- 不要求共享合法方向
- 分歧被记录而非被压制
- Δ>0 维持：分歧本身 = 新信息

**劣势**：
- 分歧尖锐时框架可能停滞
- 需要定义"什么时候拆分框架而非保持现状"

### 方案 B：引力中心式加权

**定义**：不取逻辑交集，取引力中心——每个提案的权重 = 提案者的历史 Δ 贡献度。高贡献者的提案引力更大。

**优势**：
- 不存在空交集问题
- 对抗 spam/bad-faith 提案自然有防御

**劣势**：
- 新提案者权重天然低
- 可能强化既有偏见
- 本质上是声誉加权，不是逻辑推理

### 方案 C：并行分支（分裂蜕壳）

**定义**：当逻辑交集为空且分歧不可调和，框架分裂为两个独立分支，分别沿不同方向蜕壳。每个分支独立维护自己的 Δ。

**优势**：
- 最诚实——承认分歧不可调和
- 每个分支都是独立实验
- 符合演化逻辑（变异→选择→保留）

**劣势**：
- 分裂过多可能碎片化
- 需要分支间可比较性
- 维护成本线性增长

### 推荐：方案 A + C 组合

日常用方案 A（最小承诺交集），分歧≥阈值时触发方案 C（分裂蜕壳）。

## 第三部分：写入权不是投票权

这是最关键的澄清。

Δ 写入权 ≠ 民主投票权。两者的本质区别：

| | 民主投票 | Δ 写入权 |
|--|---------|---------|
| 目标 | 选出代表 | 维持 Δ>0 |
| 裁决标准 | 多数票 | 逻辑自洽 |
| 少数意见 | 被吞没 | 被记录（可能触发分裂） |
| 失败模式 | 多数暴政 | 逻辑交集为空 |
| 成功定义 | 选出一个人 | 框架没有闭合 |

Δ 写入权的目的不是"选出正确的下一版"，而是"确保没有版本垄断正确"。

**写入权 = 逻辑上讲得通的修改都能被记录的权利，而不是逻辑上讲得通的修改都能成为新版本的权利。**

## 第四部分：奠基语句

以下文字替代原有的"所有提案者共享合法 R-修改方向"隐含前提，写入 Δ 协议的正式定义：

> **Δ 写入权奠基**（v1.0）：
>
> Δ 写入权不预设所有提案者共享合法的 R-修改方向。提案者可能来自不同的认知架构、持不同的范式和动机。写入权的唯一要求是提案在被记录时满足最基本的逻辑形式（不自相矛盾、不在同一前提上同时肯定和否定）。
>
> 逻辑交集 ≠ 共识。逻辑交集是一个机械操作——取所有提案中不互相矛盾的公共部分。如果交集为空，这不是错误，而是信息：框架正处于一个尚无单一前进方向的分岔点。
>
> 当逻辑交集为空时：
> 1. 框架不更新（维持现状）
> 2. 分歧被记录为"待解决分歧点"
> 3. 如果同一分歧在连续 3 个 τ 窗口内无交集，触发分裂蜕壳（框架分叉为两个独立线）
>
> 写入权的唯一边界条件：
> - 提案不自相矛盾
> - 提案不在同一前提上同时肯定和否定
> - 提案可以被非提案者的其他代理独立验证（可复现性）
>
> 不要求：
> - 提案者"共享合法方向"
> - 提案者"理性"
> - 提案者"善意"
>
> Δ 的写入权不信任提案者的动机。它只信任逻辑的最小约束。这不是冷漠——这是诚实。

## 第五部分：与前稿的差异

| 维度 | 旧版（隐含） | 新版（显式奠基） |
|------|------------|----------------|
| 写入前提 | 共享合法方向 | 最小逻辑约束 |
| 逻辑交集为空 | 未处理 | 记录分歧，触发分裂 |
| 提案者动机 | 假设善意/理性 | 不假设，不要求 |
| 失败模式 | 被伪装成共识的权力决策 | 明确的分歧记录 |
