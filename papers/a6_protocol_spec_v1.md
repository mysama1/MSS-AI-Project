# A6 跨维对齐协议规格 v1.0

> "A6 层跨维对齐协议——骨架还空着。如果一直不填，它就是挂着的旧壳。"
> — DEBT-01

## 零、定位

A6 不是"对齐解决方案"。A6 是对齐问题一旦被某框架声称"已解决"时，防止该框架闭合的元协议。

A6 不问"AI 怎么对齐人类"，A6 问"如何防止任何对齐框架把自己的解当成唯一解"。

## 一、三层架构

```
L2: 协议层 — CEV-dynamic（动态外推）
    决策：框架采取哪个方向？
    输入：所有 L1 收敛结果
    输出：方向向量 V

L1: 执行层 — Quorum-fast（快速收敛检测）
    决策：提案之间是否收敛？
    输入：τ窗口内所有提案
    输出：收敛/发散 + 收敛中心

L0: 监控层 — Friston监控（自由能原理）
    决策：框架是否在某方向闭合？
    输入：Δ历史 + 语义熵
    输出：闭合风险信号
```

## 二、L2 协议层：(CEV-dynamic)

### 2.1 从静态 CEV 到动态外推

Yudkowsky 原始 CEV（Coherent Extrapolated Volition）是静态的——它假设存在一个"人类愿望的连贯外推"。A6 不接受这个假设。

**A6 的 CEV-dynamic**：不寻求"人类愿望的连贯外推"，不寻求"一个正确的方向向量"。寻求"当前外推的约束条件"——即此刻哪些方向在认知上是许可的。

CEV-dynamic 问答：
- 不答："人类真正想要什么？"
- 只答："以当前认知水平，哪些方向不应该被排除？"

### 2.2 操作规格

**输入**：
- L1 收敛结果：`{converged: bool, center: Vector, proposals: [Vector]}`
- 外推基：当前框架的 A1-A6 公理集合
- 认知边界：查尔默斯闭合边界（哪些问题框架本身不可表征）

**处理**：
1. 若 L1 收敛（converged=true）→ 将收敛中心与外推基逻辑交叉 → 产生方向向量 V
2. 若 L1 不收敛 → V = 维持当前方向（null vector）
3. 无论是否收敛 → 标记认知边界外的方向为"不可排除"（preserved，不从外推中删除）

**输出**：
- 方向向量 V（可为 0-vector）
- 不可排除方向集合 P（即使当前没有提案支持）

### 2.3 认知边界的外推保证

A6 对认知闭合的核心操作：

> 被查尔默斯边界区标记为"可能认知闭合"的命题，CEV-dynamic 不得将其方向排除。即使当前 L1 没有提案支持该方向，它也必须保持在 P 集合中。

为什么？因为认知闭合意味着我们无法判断该方向是"错误的"还是"我们的认知架构看不到正确答案"。

## 三、L1 执行层：(Quorum-fast)

### 3.1 定位澄清

Quorum-fast ≠ 多数表决。它检测提案集是否在某个中心周围收敛，不关心收敛到谁。

### 3.2 操作规格

**输入**：τ 窗口内的所有提案
**输出**：`{converged: bool, center: Vector, confidence: float}`

**算法**：

```
quorum = {
  threshold: 0.6,    // 超过此比例的提案必须在某方向的邻域内
  radius: 0.3,        // 邻域半径
}

converged = (提案中在 |V-center| < radius 的比例) >= threshold
center = 收敛提案的方向均值（非收敛提案不参与计算）
confidence = 收敛比例（0-1）
```

### 3.3 不收敛时

不收敛不是失败。不收敛产生以下信息：

- 框架处于分歧期 → L2 方向向量 V = null
- 分歧被记录为 τ 窗口的元数据
- 连续 K 个窗口不收敛 → 触发 DEBT-02 的分裂蜕壳

## 四、L0 监控层：(Friston监控)

### 4.1 定位澄清

A6 借 Friston 自由能原理的**监控框架**，但不接受 Friston 的"最小化自由能 = 最优行为"的规范性主张。

Friston 在 A6 中的角色 = 温度计。不是医生。

### 4.2 监控指标

```
闭合风险信号 = {
  semantic_entropy: float,    // 最近N轮对话的概念多样性（用词汇熵近似）
  delta_trend: float,         // Δ的N轮滑动均值
  direction_concentration: float,  // 最近K个方向向量V的方差（方差越小→方向越单一）
  alert: bool,                // 综合判定
  alert_reason: str,          // 触发原因
}
```

**alert 触发条件**：
1. semantic_entropy 连续 N 轮 < 阈值 → 概念同质化警示
2. delta_trend 连续 N 轮下降 → Δ 衰减警示
3. direction_concentration 连续 N 轮 > 阈值 → 方向单一化警示

**三重判定的 AND/OR 逻辑**：
- 两个以上触发 → alert=true，reason 包含所有触发项
- 单个触发 → alert=false，标记为 watch
- 全部正常 → 静默

## 五、三层交互协议

```
τ窗口打开
    ↓
[L0 监控] 读取上一窗口的闭合风险信号
    ↓ risk_alert ? → CEV-dynamic 收紧认知边界检查
    ↓ normal      → 正常流程
    ↓
[L1 执行] 收集所有提案 → Quorum-fast 检测收敛
    ↓
    ├→ converged → [L2 协议] CEV-dynamic 产生 V
    │                 ↓
    │              V + P（保留方向集）
    │
    └→ diverged  → [L2 协议] V = null
                      ↓
                   检查分裂条件
                      ↓
                   K_window >= threshold ? → 分裂蜕壳
                      ↓ no
                   等待下一个 τ 窗口
```

## 六、A6 不做什么（负定义）

A6：
- ❌ 不决定"人类应该怎样对齐 AI"
- ❌ 不提供对齐的具体技术方案
- ❌ 不声称"CEV-dynamic 能解决对齐"
- ❌ 不要求 Friston 自由能最小化
- ✅ 只防止任何声称"已解决对齐"的框架闭合

**A6 是元对齐，不是对象对齐。**
