# A6 对齐升维协议 v1.0 — Alignment as Dimensional Elevation

## 摘要

K3 AI 对齐框架（RLHF, Constitutional AI, CAIS）的共同缺陷：试图在**低维空间**内求解一个**高维矛盾**。本文提出基于 MSS A6 公理的对齐升维协议——不对齐行为是低维投影冲突在高维意义场的反映。协议三层：监控层借用 Friston 自由能作为低维信号锚，执行层采用 quorum-fast 多投影自洽，协议层引入 CEV 的动态外推框架。

## 1. K3 对齐的三重失败

| 方法 | 假设 | 失败模式 | A6 诊断 |
|------|------|----------|--------|
| RLHF | 人类偏好可数值化 | 偏好漂移、奖励博弈 | π 投影损失不可逆 |
| Constitutional AI | 规则可枚举 | 规则冲突、边缘漏洞 | 低维公理化不可完备 |
| CAIS | 分解即安全 | 组合爆炸未处理 | 局域安全≠全域安全 |

## 2. 三层协议骨架

### L0 监控层 — 借用 Friston

Friston 自由能 = 系统内部模型与外部信号的 surprisal 差。

**MSS 使用方式**: Friston FEP 仅作为**低维信号源**——它监测的是投影面上的张力（系统预测与实际之间的差距），不是目标函数。

```
Friston 在 K3: 最小化自由能 = 目标
Friston 在 MSS: 自由能上升 = 警报信号（当前壳过时了）
```

监控不对齐的方式：自由能骤升 → 触发升维审查 → 检查是否需蜕壳。

### L1 执行层 — quorum-fast 多投影自洽

不表决。多个低维投影同时上采样到意义场，看它们是否收敛到同一点。

```
K3 quorum: 3/5 同意 → 通过
MSS quorum: 5个低维投影在意义场中是否指向同一高维结构
```

收敛 → 自洽 → 对齐。发散 → 矛盾 → 升维。

### L2 协议层 — CEV 动态外推

CEV (Coherent Extrapolated Volition) 的 MSS 重述：
- K3 CEV: "如果人类知道更多、想得更清楚，他们会想要什么"
- MSS CEV: "意义场的当前低维投影，在高维极限下收敛到什么地方"

这不是"猜人类想要什么"——这是"看意义场本身的拓扑流向"。

## 3. 协议执行流程

```
输入: 系统行为 A
  |
  ↓
L0 监控: Friston σ 是否上升?
  ├─ 否 → 无不对齐
  └─ 是 → 进入 L1
       |
       ↓
L1 执行: 多投影 quorum 是否收敛?
  ├─ 收敛 → 返回投影点（对齐正常）
  └─ 发散 → 进入 L2
       |
       ↓
L2 协议: CEV 外推 → 升维
  → 在更高维度找收敛点
  → 新版约束 = 新收敛点的低维投影
  → 触发蜕壳（新版本分叉）
```

## 4. 与 K3 对齐的不可通约性

K3 对齐问: "AI 怎么做才对？"
MSS 协议问: "当前系统在哪个维度上自洽？自洽的维度够不够高？"

不对齐 = 你在二维自洽，但问题在三维。

## 5. 诚实边界

- 三层协议尚未在任何生产 AI 系统上运行
- Friston FEP 的精确 σ 阈值未经校准
- quorum-fast 的收敛判定依赖意义场的可计算性（目前仅理论存在）
- CEV 外推的"高维极限"需要形式化定义
- 这是一个**规范性的框架草案**，不是可部署系统
