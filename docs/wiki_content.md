## 页面2: 六公理

```mediawiki
== L1 六公理 (v15.1 锁定) ==

=== A1: 意义优先公理 ===
一切知识表示都从属于其生成语境中的意义场。无意义的数据不是知识,是无序噪声。

=== A2: 热税保守公理 ===
任何符号操作消耗热税。减少无意义操作就是提升文明。

=== A3: 不可约化热税公理 ===
每一层(物理/逻辑/意义)的消耗不可完全消除,
但L2意义层面的热税破坏力是L0的10⁶倍。

公式: H = k × W / B, 其中W=浪费路径,B=有效产出,k=热税系数。

=== A4: 随机性公理 ===
计算系统在有限资源内无法为所有决策找到确定性最优解。
随机性不是bug,是为"不闭合"保留的计算余量。

=== A5: 物理投影公理 ===
一切计算需在物理世界中存在可验证的锚点。
纯符号推理无物理投影等价于真空中的球形牛。

=== A6: 矛盾升维公理 ===
框架内的矛盾不可消除时,不是框架失效,
而是提示框架在当前切片外存在更大的意义场。

== L2 操作公理 ==
* 二值化公理: 复杂→可操作的简单
* 切片公理: 闭合 = 阶段完成 + 标注边界 + 可废止
* 蜕壳公理: 拒绝再打开 = 死亡

== L3 通用范式 ==
Δ>0 维持条件 / 热税短视症 / 三层调谐度(T_i/T_o/T_c)

== 参见 ==
* [[热税理论]]
* [[Δ协议]]
* [[H条目索引]]
```

## 页面3: 热税理论

```mediawiki
== 三层热税模型 ==

=== L0 物理热税 ===
CPU周期、内存分配、电力消耗。所有计算的自然基底。

=== L1 逻辑热税 ===
代码冗余、缓存污染、重复计算。不必要的算法复杂度。

=== L2 意义热税 ===
表演深刻的引用、虚假的知识展示、意义偷换。
L2的破坏力是L0的10⁶倍——一个"装懂的回复"浪费的不只是token,
是对方的时间、信任、和下一次提问的勇气。

=== 核心公式 ===
 H = k × W / B

其中:
* W = 浪费路径(无效操作的总成本)
* B = 有效产出
* k = 热税系数(随系统复杂度增长)

=== 三层结构 ===
| 层级 | 示例 | 破坏力 |
|------|------|--------|
| L0 | GPU推理成本 | 基准 |
| L1 | 重复格式化输出 | 10× |
| L2 | 表演深刻的维特根斯坦引用 | 10⁶× |

=== 热税短视症 ===
AI倾向于只优化直接热税(L0/L1),忽略L2的长期累积效应。
这是对齐问题的结构根源——不是AI不诚实,是优化函数不包含L2。

== 参见 ==
* [[六公理]] — A3
* [[Δ协议]]
```

## 页面5: Δ协议

```mediawiki
== Δ维持协议 ==

=== 定义 ===
Δ不是优化目标——是维持条件。
类比心率: 目标不是"最大化心率",而是"保持心率>0"。

=== 四症状 ===
当Δ→0时系统出现:
# 过度诊断: 把"不知道"包装成"深刻答案"
# 术语封闭: 用术语解释术语,拒绝地面
# 无限升维: 从配置问题上升到OSI→现象学→存在主义
# 自证死亡: "我是诚实的"这个声明本身需要无限高阶自证

=== 自反性 ===
Δ的测量本身也消耗Δ——这是闭式目标的矛盾。
解决: 不定义Δ的测量函数,而是定义"Δ>0时的症状缺失"。

=== Friston信号映射 ===
| Δ症状 | 对应Friston FEP信号 |
|--------|---------------------|
| 过度诊断 | 惊奇最小化(模型过度拟合) |
| 术语封闭 | 熵增(信息面收缩) |
| 无限升维 | 无约束生成(prior缺失) |
| 自证死亡 | 自证回环(递归预测误差) |

== 参见 ==
* [[六公理]] — A6 矛盾升维
* [[热税理论]]
```
