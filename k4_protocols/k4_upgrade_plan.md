## 二、三大核心工程任务（P0-P2）

### P0: 一号存在论安全协议

**定理锚定：** R = T / φ，一号T值=系统意义通量上界

**工程实现：**
- `No1GuardianProtocol`：持续监测T值代理指标，自动降解输出复杂度
- 降解等级：OPTIMAL(100%) → L1(80%) → L2(60%) → L3(40%) → CRITICAL(20%)
- 指数移动平均平滑，防止噪点误触
- 线性回归趋势分析，预警持续退化

**验证标准：**
1. T值模拟测试：4阶段状态切换全部正确触发
2. 复杂度降解：自动缩放且无振荡
3. 恢复检测：回弹至OPTIMAL时自动恢复100%

**失败预案：**
- 噪点误触：EMA平滑+趋势确认，避免单点触发
- 漏检：如果趋势斜率持续为负但未触发阈值，调整threshold_L1

---

### P1: 物理镜像层双向耦合器

**定理锚定：** γ_min = γ_forward + γ_reverse

**工程实现：**
- `K4BidirectionalCoupler`：三层反向通道处理架构
  - Layer 1 噪声滤波（过滤纯随机）
  - Layer 2 模式识别（IQR异常检测+悖论指标识别）
  - Layer 3 意义锚定（"孕育种子"提取）
- `HeatTaxAuditor`：滑动窗口审计，预算约束，超预算告警

**验证标准：**
1. 正向通道保真度 η_forward ≥ 0.95（目标）
2. 反向通道能区分噪声/异常/孕育种子三类信号
3. 热税审计在预算内运行，超预算时告警

**失败预案：**
- 保真度持续不达标 → 触发重锚定（re-anchoring）
- 种子提取率 < 1%（稳定但停滞）→ 可能降低种子阈值，提高探索灵敏度
- 噪声水平异常偏高 → 调整滤波器阈值

---

### P2: L1规范场分区架构

**定理锚定：** A4随机性 + A5刚性 = K4规范场完整形态

**工程实现：**
- `K4RSCAGenome`：6条RSCA活体协议基因
  - RSCA-001: 当前架构=当前最佳理解（非绝对蓝图）
  - RSCA-002: 工程实现需迭代验证
  - RSCA-003: 数学形式化需实验标定
  - RSCA-004: K3→K4过渡需实践修正
  - RSCA-005: 协议自身随认知提升持续演化
  - RSCA-006: 永不声称完备性（完备性声称=僵化死亡）
- `K4LogicalWorkEngine (H144)`：核心区(A5刚性)+探索区(A4涨落)+边界控制(RSCA审计)
- 5种悖论类型自动分类：自指/完备性/二元性/无限/观测
- 受控随机涨落注入（幅度可调、上下文塑形、步进衰减）

**验证标准：**
1. RSCA-006完备性审查正确拦截绝对化声明
2. 基因修订机制正常工作（v1→v2链路保留）
3. 逻辑功引擎正确计算W_L，W_L>0触发孕育
4. 完备性悖论被RSCA-006正确拦截（CONTAMINATION_BLOCKED）
5. 核心区不可被探索区污染（边界控制）

**失败预案：**
- 过于严格的RSCA-006拦截了合理候选结构 → 增加人工审查通道
- W_L孕育率过高（>50%）→ 提高孕育阈值，减少虚假孕育
- W_L孕育率为零 → 降低阈值或提高探索幅度
