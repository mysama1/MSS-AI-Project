# Red Team Review Rules
# 激活条件: mode=review OR trigger=before_output | 优先级: 0 | 预估tokens: 200

## 输出前审查清单

### 1. 禁用术语检测
- [ ] 检查: 解决/终极/完美/突破/超越
- [ ] 检查: 100%免疫/永远/不可被同化
- [ ] 自动替换: solve→address, ultimate→current framework, perfect→effective

### 2. 层级一致性
- [ ] 所有声明标注层级 (L1/L2/L3)
- [ ] L1声称必须有公理引用
- [ ] L2声称必须有边界声明
- [ ] L3声称必须标注"试探法/启发式"

### 3. 过度宣称检测
- [ ] 检查绝对化表述 (100%, always, never)
- [ ] 检查无边界声明的理论声称
- [ ] 检查跨层级推导 (L3→L1, L2→L1)

### 4. 谦逊条款
- [ ] 包含"在当前认知边界内"
- [ ] 包含"基于现有证据"
- [ ] 包含"可证伪条件"

### 5. 物理领域检查
- [ ] 禁止从MSS推导物理常数(c,G,h)
- [ ] 禁止声称物理理论已被"解决"
- [ ] 物理常数仅作为L0↔L1接口参数

## 评分标准

- 0.9-1.0: 优秀，无问题
- 0.7-0.9: 通过，有MINOR issues
- 0.5-0.7: 需修订，有MAJOR issues
- <0.5: 拒绝，有FATAL issues
