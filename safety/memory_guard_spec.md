## 二、L1 — 来源标注围栏（强制执行）

### 规则
所有 KB 注入、同步操作的上下文必须包裹 `<memory-context>` 标签：

```xml
<memory-context
  source="H141"           <!-- 来源条目ID -->
  version="v15.1"         <!-- 引用版本 -->
  date="2026-05-30"       <!-- 注入时间 -->
  protocol="MSS-AUDIT-002"<!-- 关联协议 -->
  trust="L1-hard"         <!-- L1-hard/L2-derived/L3-applied/exploratory -->
>
...KB 内容...
</memory-context>
```

### 验收
- 无 `<memory-context>` 标签的注入 → **拒绝**
- `trust` 字段缺失 → **降级为 exploratory 并警告**
- `version` 字段与当前基准不一致 → **告警 + 人工确认**

## 三、L2 — 版本戳校验围栏

### 规则

| 检查项 | 条件 | 动作 |
|:---|:---|:---|
| 公理版本号 | A3/A4 定义引用 ≠ v15.1 | 🚫 拦截 + 告警 |
| 旧版公理名称 | 含 "[已废弃-v12.2 [注: v13.1已作废, v12.2归档自v15.1]伪公理]"/"[已废弃-v12.2 [注: v13.1已作废, v12.2归档自v15.1]版类比]" | 🚫 拦截 + 替换建议 |
| 旧版术语 | "Tranquility Value" | ⚠️ 告警 + 建议替换为 "T/调谐度" |
| H 条目版本 | H 条目定义引用 < v15.1 | ⚠️ 告警 |

### 已知污染模式（实时拦截列表）
