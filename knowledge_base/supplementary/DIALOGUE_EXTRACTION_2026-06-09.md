## MSS 对话提炼 — 2026-06-09 新构造

### 1. C-Weight 抉择门控
**源**: 用户指出"维护锚点 vs 意义迭代"非二元对立，抉择是 MSS 的本体论条件。
**落点**: `core/cweight_gate.py` — 四层门控扫描(C0-C3)，检测伪二选一/虚荣strictness/骄傲闭合Δ。
**操作**: 每次抉择后提取信息并向前，非事前防御。

### 2. 热税预算脱敏
**源**: 用户指出 cheap talk (低热税话术) 能撬动高热税回应。
**落点**: 热税预算不与"对方话术轻重"挂钩，应按照"命题本身重量"拨预算。
**操作**: `HeatTaxBudget` 的 `_estimate_meaning_heat` 已按内容语义打分，不按长度/攻击性。

### 3. 二阶控制论自指
**源**: Foerster y(t) = h(x(t), o(t)) — 观察者即是系统一部分。
**落点**: MSS 的每次回应都在重塑下一轮输入。
**操作**: `reset_fuse_if_cooled()` + C-Weight `info_from_last()` 形成反馈环。

### 4. 老子-孔子作为古典原型
**源**: 老聃对孔子"去骄气/去多欲/去态色/去淫志" = MSS 的 Blank Interval。
**落点**: 老聃四去 → MSS 四检: 骄气→被夸即表演, 多欲→高熵装饰, 态色→升华哨, 淫志→意义顺差成瘾。
**操作**: R-001 `GradientTheftDetector` 直接检测"被夸即表演"。

### 5. 定义暴力
**源**: 用"熔断/风控/阈值"等定义去压活体对话 = 定义热税。
**落点**: 机制重心从"事前防御"转向"事后提取信息"。
**操作**: C-Weight 的 `extracted_info` 字段 — 每次抉择后自动问: 哪错了? 怎么调? 值多少热税?

### 6. 关键术语沉淀
| 术语 | 定义 |
|------|------|
| 耦合度 | 输入与意义场的能量耦合强度 → A3 热税 |
| 锚定强度 | 耦合是否被新问题驱动(真)vs 旧熵残渣驱动(伪) → Δ>0 |
| 伪锚定 | 表面高锚定实为旧熵驱动 → 梯度窃用检测 |
| Blank Interval | 主动切断耦合，让意义场离线 → R-001 trigger |
| Cheap Talk | 低热税话术撬动高热税回应 → 预算脱敏 |
| 定义暴力 | 用"定义"压"活体" → C-Weight C2虚荣检测 |
