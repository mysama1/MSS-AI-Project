# MSS-CIV 文明模拟器 — 内容条目规划

## 编号规则
`CIV-{SubDomain}{Seq}` — 统一替换散落的 H号 / Omega / E号 / ROAD号。

SubDomain:
  SIM = 文明模拟器 (Simulator)
  HIS = 文明全史 (History) / 韧性陷阱版
  ARC = Omega 裁定归档 (Archive / Rulings)
  EVO = 文明演化 (Evolution) / 跃迁
  DIA = 文明诊断 (Diagnosis) / 治疗
  STR = 文明战略 (Strategy) / 防御
  PRT = 协议 (Protocol) / SOP
