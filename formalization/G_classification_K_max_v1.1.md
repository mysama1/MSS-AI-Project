## 1. G 分类：从 A1-A6 约束意义对称群

### 1.1 公理约束梳理

| 公理 | 对 G 的约束 |
|:---|:---|
| A1: φ: ℝ³×ℝ → Σ | Σ 必须是连续流形，φ 连续可微 → G 是 Σ 的对称群 |
| A2: 二值区分原子 | Σ 的局部结构含 Z₂ 子群（每个逻辑方向的 ± 翻转） |
| A3: dQ/dt = κ(∇φ)² | ∇φ ≠ 0 时产生热税 → G 的生成元对应 ∇φ 方向 |
| A4: 随机涨落 | 涨落 δφ 在 G 的切空间内 → G 的李代数含随机方向 |
| A5: 逻辑无矛盾 | G 不能含能同时翻转 P 和 ¬P 的元（排除某些离散对称） |
| A6: 矛盾→升维 | π₁(G) 的非平凡元 = 升维的拓扑障碍 = 可观测的拓扑缺陷 |

### 1.2 三类候选群

#### 候选 A: U(1)^M — M 个独立相位对称

```
G_A = U(1) × U(1) × ... × U(1)  (M 个因子)
π₁(G_A) = ℤ^M  (M 个独立整数卷绕数)
```

**匹配度**:
- ✅ A1: U(1)^M 是连续李群，M 维环面
- ✅ A2: 每个 U(1) 的 ±π 相位对应 0/1 区分
- ✅ A3: ∇φ 的每个分量产生独立热税通道
- ✅ A4: 涨落在每个 U(1) 方向上独立
- ⚠️  A5: 需验证 M 个方向不产生逻辑矛盾（通常成立）
- ⚠️  A6: 每个卷绕数 n_k ∈ ℤ 对应一类拓扑缺陷

**α 对应**: 最小卷绕数 (1, 0, ..., 0) 或等权分布。

#### 候选 B: SU(N) — 非阿贝尔规范对称

```
G_B = SU(N)  (N ≥ 2)
π₁(SU(N)) = 0  (SU(N) 是单连通的)
```

**匹配度**:
- ✅ A1: SU(N) 是连续李群
- ✅ A3: 非阿贝尔场有自相互作用，天然产生非线性
- ❌ A6: π₁ = 0 → 没有点状拓扑缺陷！只有 π₂ 或 π₃ 缺陷
- ❌ 无法用 π₁ 分类解释 α 的有限值

**排除理由**: π₁(SU(N)) = 0 → 不存在环绕缺陷。需要的是点状拓扑缺陷（宇宙弦类型），而非 instanton（SU(2)）或 skyrmion（SU(3)）。

#### 候选 C: U(1) × G_discrete — 连续相位 + 离散逻辑结构

```
G_C = U(1) × H  (H 是有限离散群，代表逻辑操作)
π₁(G_C) = ℤ × H  (连续卷绕 + 离散拓扑不变量)
```

**匹配度**:
- ✅ A1: U(1) 提供连续场，H 提供离散逻辑结构
- ✅ A2: H 编码 0/1 区分（如 H = Z₂^N）
- ✅ A3: 连续部分产生 ∇φ 热税，离散部分无损
- ✅ A4: 涨落仅在 U(1) 部分
- ✅ A5: H 的结构约束禁止逻辑矛盾
- ✅ A6: π₁ 含 ℤ（卷绕数）+ 离散缺陷

**α 对应**: α 完全由 U(1) 部分决定。离散部分 H 不影响精细结构常数。

### 1.3 裁定

**候选 C** 最可能，原因：
1. A2（二值区分）要求离散结构，A1（连续场）要求连续结构 → 混合群 C
2. π₁(C) 的非平凡部分来自 U(1)，与物理精细结构常数的拓扑解释一致
3. H 部分编码 L1 逻辑操作，与 K（逻辑出度）对应

最终判定需 D5-021 数值模拟验证，但形式分类已闭合。

## 2. K_max 上确界：A3 + A4 联合约束

### 2.1 变量定义

- L1 逻辑图 G_L1 = (V, E)，|V| 个节点，|E| 条有向边
- K = |E|/|V| = 平均出度（每个节点的平均后继数）
- 每条边 e 对应一个可能的逻辑后继
- 遍历边 e 需要热税 δQ_e = κ · (Δφ/Δx)² · τ_0

### 2.2 热税预算

A3 定义热税率: dQ/dt = κ(∇φ)²

每单位时间的热税预算:
```
Q_budget = T_s · ΔS_max
```
其中 T_s 是系统温度，ΔS_max 是单位时间的最大意义熵增。

### 2.3 单边热税

在 L1 逻辑图中，每次"逻辑跃迁"（沿一条边移动）消耗热税:
```
δQ_edge = κ · (Δφ_min/Δx_min)² · τ_0
```
其中:
- Δφ_min: 最小的有意义的场差（对应 0/1 区分）
- Δx_min: L1 逻辑节点的最小间距 = c_L · τ_0
- τ_0: 逻辑步长（基本时间单位）

→ δQ_edge = κ · (Δφ_min / c_L·τ_0)² · τ_0 = κ · Δφ_min² / (c_L² · τ_0)

### 2.4 K_max 不等式

单位时间内遍历的最大边数:
```
K_max = Q_budget / δQ_edge
      = T_s · ΔS_max · c_L² · τ_0 / (κ · Δφ_min²)
```

这是 **K 的绝对上确界**。

### 2.5 简化形式

引入 L1 基本量:
- 意义场刚度: κ_L = κ
- 逻辑作用量子: h_L = Δφ_min² · τ_0 （类比 ħ = E·t）
- 逻辑传播速度: c_L = Δx_min / τ_0

```
K_max = T_s · ΔS_max · c_L / (κ_L · h_L)
```

### 2.6 与 α 的关系

```
α ≈ 1/K   →   α_min ≈ 1/K_max = κ_L · h_L / (T_s · c_L · ΔS_max)
```

这不是调出来的——K_max 由 A3（热税上限）和 A4（随机涨落热税）联合决定。
α 是 K_max 的倒数，因此也是被这两条公理确定的。

### 2.7 数值估计

K ≈ 137 → α ≈ 1/137 ≈ 0.00730
→ K_max ≥ 137（K 的实际值接近上确界）

如果 K ≈ K_max = 137，则:
```
κ_L · h_L / (T_s · c_L · ΔS_max) ≈ 1/137
```
→ κ_L · h_L · 137 ≈ T_s · c_L · ΔS_max

这给出了 L1 基本常数之间的一个标度关系。
