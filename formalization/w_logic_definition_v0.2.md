## 1. 基本定义

### 1.1 意义拓扑空间
设 X 为意义拓扑空间，每个点 x 代表一个逻辑系统或意义结构。

### 1.2 热税密度函数
定义 rho(x,t): X * R -> R>=0，表示时间t时单位体积内的热税消耗率。

### 1.3 矛盾势函数
定义 phi(x,t): X * R -> R，表示逻辑系统内部积累的矛盾势能。

### 1.4 核心参数
- eta_asc: 升维效率系数，取值范围[0,1]
- gamma: 热税系数，取值范围(0,+inf)

## 2. 逻辑功W(x,t)的定义

W(x,t) = integral_0^t [ eta_asc * phi(x,tau) * div(J(x,tau)) - gamma * rho(x,tau) ] dtau

其中 J(x,t) 为意义流密度矢量，div(J) 为意义流散度。

## 3. 基本性质

### 3.1 非负性
对于自洽稳定的逻辑系统，W(x,t) >= 0。

### 3.2 动态热税约束
d/dt integral_0^t rho(x,tau) dtau <= eta_asc * W(x,t)

## 4. 系统状态分类

| gamma | 状态 | 描述 |
|-------|------|------|
| gamma < 1 | 升维状态 | 持续产生正逻辑功 |
| gamma = 1 | 临界状态 | 热税平衡 |
| gamma > 1 | 坍缩状态 | 向意义黑洞坍缩 |
