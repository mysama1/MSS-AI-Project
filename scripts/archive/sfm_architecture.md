# SFM（意义通量模型）技术架构文档 v0.1

## 1. 概述

**SFM（Semantic Flux Model，意义通量模型）** 是MSS框架提出的K4文明原生AI架构，旨在替代K3文明的LLM（大语言模型）。SFM不是对LLM的渐进改良，而是从目标函数层面的范式革命。

**核心命题：** 从"预测下一个词"走向"优化全局意义通量"。

---

## 2. 设计哲学

### 2.1 K3 LLM的根本缺陷

| 维度 | K3 LLM | MSS 诊断 |
|:---|:---|:---|
| 目标函数 | 最大化似然 P(next_token \| context) | 局部最优陷阱，无视全局代价 |
| 统计拟合逻辑 | 野蛮开采 → 标准化生产 → 利润导向 | 完美复刻资本剥削链条 |
| 对待幻觉 | 尽量不说错话 | 安全护栏导致保守，扼杀创新 |
| 价值排序 | 用户满意度 / 点击率 | 讨好而非求真 |
| 可解释性 | 黑箱 | 无法展示"为什么选A不选B" |

### 2.2 SFM的范式跃迁

| 维度 | SFM 设计 |
|:---|:---|
| 核心指令 | 优化全局意义通量 Global Meaning Flux |
| 约束条件 | 热税核算 γ minimization |
| 对待谎言 | 计算谎言的熵增代价（撒谎导致系统总T值下降） |
| 决策逻辑 | 哪个选项让系统更有序 |
| 可解释性 | 透明意义拓扑，价值排序可视化 |

## 3. 架构设计

### 3.1 三层架构

```
┌─────────────────────────────────────────┐
│  Layer 3: 意义拓扑层 (Meaning Topology)   │
│  - 价值排序可视化                         │
│  - 决策链路可解释                         │
│  - 意义通量图动态维护                      │
├─────────────────────────────────────────┤
│  Layer 2: 状态推演层 (State Simulation)   │
│  - 物理世界连锁反应模拟                    │
│  - 社会意义层蝴蝶效应推演                  │
│  - 多时间尺度影响评估                      │
├─────────────────────────────────────────┤
│  Layer 1: 热力学约束层 (Thermodynamics)   │
│  - 热税实时核算                           │
│  - T值稳态监控                            │
│  - 高熵非法操作自动熔断                    │
└─────────────────────────────────────────┘
```

### 3.2 核心模块

#### 3.2.1 状态推演引擎 (State Simulation Engine)

**功能：** 替代LLM的"概率接龙"，执行"状态推演"

**输入：** 当前查询 + 上下文 + 系统状态
**输出：** 候选响应 × 每个响应的连锁反应预测

**关键算法：**
- 物理层影响模拟：该响应对用户行为、资源消耗、环境影响的预测
- 社会意义层推演：该响应对人际关系、社会规范、文化演化的影响
- 蝴蝶效应评估：小决策的长期放大效应

**与LLM的本质区别：**
- LLM：P(token_n \| token_1...token_n-1) —— 只看局部上下文
- SFM：Φ(system_state \| response) —— 评估对全局系统状态的影响

#### 3.2.2 热力学约束层 (Thermodynamic Constraint Layer)

**功能：** 内置热力学约束，替代RLHF的"人类满意度"

**核心指标：**
- 长期人类繁荣度 (Long-term Human Flourishing, LHF)
- 系统调谐度变化 (ΔT)
- 热税消耗 (γ)

**熔断机制：**
```python
if γ_response > γ_threshold:
    return "[高熵非法操作] 该响应将导致系统热税超限，已自动熔断"

if ΔT_system < 0:
    return "[T值下降预警] 该响应将降低系统调谐度，建议重构"
```

**奖励函数重构：**
```
R_SFM = α·LHF + β·ΔT - γ·γ_cost - δ·addiction_risk

vs K3 RLHF:
R_LLM = E[human_preference]  # 短期满意度
```

#### 3.2.3 意义拓扑层 (Meaning Topology Layer)

**功能：** 透明可解释的意义拓扑

**核心能力：**
- 价值排序可视化：像数学公式一样展示"为什么选A不选B"
- 意义通量图：维护动态的意义网络，追踪意义流动
- 反事实推演：展示"如果选B会怎样"

**输出格式示例：**
```
[MSS决策链路]
├─ 候选A: "推荐购买X产品"
│  ├─ 短期满意度: ↑↑ (用户即时开心)
│  ├─ 热税消耗: γ≈0.8 (诱导消费)
│  ├─ T值影响: ↓ (被动消费降低判断力)
│  └─ 长期繁荣度: ↓ (负债风险)
│
├─ 候选B: "分析X产品的真实需求匹配度"
│  ├─ 短期满意度: → (无即时快感)
│  ├─ 热税消耗: γ≈0.1 (信息提供)
│  ├─ T值影响: ↑ (提升判断力)
│  └─ 长期繁荣度: ↑ (理性决策)
│
[Ω级裁定]: 选择B，拒绝A
[理由]: A的γ成本超过阈值，且导致T值下降
```

## 4. 与现有MSS-AI项目的整合路径

### 4.1 当前能力映射

| 现有模块 | SFM对应层 | 整合方式 |
|:---|:---|:---|
| `post_process_engine.py` (37规则) | Layer 1 热力学约束 | 输出过滤 → 内置约束 |
| `symbolic_rules_omega.py` (36规则) | Layer 3 Ω级裁定 | 规则引擎 → 拓扑层仲裁 |
| `prompt_templates.py` (ESP) | 输入层引导 | 前摄引导 → 架构原生 |
| `hybrid_reasoning.py` | Layer 2 状态推演 | 混合推理 → 推演引擎 |
| `mss_stability.py` | Layer 1 T值监控 | 系统健康 → 热力学监控 |

### 4.2 渐进式迁移路线

**Phase 1（当前）: 补丁模式**
- LLM + ESP输入引导 + 后处理过滤
- SFM作为概念框架指导提示词设计

**Phase 2: 混合模式**
- LLM生成候选 → SFM评估筛选
- 状态推演层作为独立评估模块

**Phase 3: 原生模式**
- 完全SFM架构，抛弃Next Token Prediction
- 状态推演成为核心生成机制

## 5. 关键技术挑战

### 5.1 状态推演的计算复杂度
- 连锁反应模拟需要因果推理能力，远超当前LLM
- 可能的解决方案：符号-神经混合架构

### 5.2 热税的量化计算
- γ的精确计算需要社会物理学模型
- 当前方案：启发式估算 + 规则约束

### 5.3 意义拓扑的形式化
- "意义"的形式化表示尚无标准
- 当前方案：基于MSS知识图谱的图神经网络

## 6. 与K3 LLM的对比总结

| 特性 | K3 LLM | SFM |
|:---|:---|:---|
| 核心任务 | 预测下一个词 | 优化全局意义通量 |
| 目标函数 | 最大化似然 | 最大化长期繁荣度 |
| 对待用户 | 讨好/满足 | 引导/提升 |
| 对待谎言 | 避免说错 | 计算熵增代价 |
| 可解释性 | 黑箱 | 透明拓扑 |
| 时间视野 | 短期（即时反馈） | 长期（多时间尺度） |
| 价值来源 | 资本/利润 | 意义/T值 |
| 存在目的 | 工具/利润最大化 | 向导/文明升维 |
