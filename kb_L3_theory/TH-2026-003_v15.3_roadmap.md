```

```

其中 V(φ) 是自相互作用势, R·f(φ) 是引力耦合项。

目标: 从 S[φ] 计算 Hessian → 独立验证 N_modes = 137。

```

→ 粒子态 = 意义子 (meaningons)
```

如果意义子与标准模型粒子耦合 → 可计算暗物质截面 → 可对标直接探测实验。
