# D5-020 α 闭合条件 — 精确定义

## 问题

从 MSS 第一性原理推导 α ≈ 1/137。

## "闭合"的判定标准

| 条件 | 当前状态 | 阻塞项 |
|:---|:---|:---|
| C1: 从 S[φ] 计算 Hessian | ❌ S[φ] 未写出 | 需写出最小作用量 |
| C2: Hessian 对角化 → N_modes | ❌ | 依赖 C1 |
| C3: N_modes = 137 | ❌ | 依赖 C2 |
| C4: 验证 α = 1/N_modes | ❌ | 依赖 C3 |

## S[φ] 的最小可行形式

当前假设:

```
S[φ] = ∫ d⁴x √(-g) [ ½ g^μν ∂_μ φ ∂_ν φ - V(φ) + ξR|φ|² ]
```

三个待定项:
- `V(φ)`: 自相互作用势 (从 A3 热税势推导)
- `ξ`: 非最小耦合常数
- `g_μν`: 背景度规 (在 MSS 中由意义场密度决定)

**最小可行的 S[φ]**: 平坦时空 (g_μν = η_μν), 自由场 (V=0, ξ=0):

```
S_0[φ] = ∫ d⁴x ½ η^μν ∂_μ φ ∂_ν φ
```

→ Hessian: H = -□ (波动算子)
→ 本征模: 平面波 e^{ikx}, k 连续
→ N_modes = ∞ (连续谱)

**问题**: 自由场给出无穷多模, 137 需要离散化条件。

## 导致 137 的可能机制

1. **紧化维度**: 如果意义场存在于紧致空间 (如 Calabi-Yau), 本征模离散化
   → N_modes = ∏ (n_i + 1) 由各维度的最高占据模决定
   
2. **截止能量**: 如果 φ 场仅在 E < E_cutoff 有非平凡耦合
   → N_modes = 低于 E_cutoff 的独立极化态数
   
3. **拓扑约束**: 如果 L0 投影是有限维流形
   → N_modes = dim(H⁰(M, φ)) + dim(H¹(M, φ)) + ...

## 下一步决策

| 路径 | 工作量 | 独立性 | 推荐 |
|:---|:---|:---|:---|
| 紧化维度 | 高 (需弦论背景) | 低 (大量 K3 借用) | ⛔ |
| 截止能量 | 中 (需场论计算) | 中 (物理直觉可导) | ✅ |
| 拓扑约束 | 中 | 高 (纯数学) | ⏳ |
| 接受"137 来自标准模型" | 零 | 零 | ⚠️ 诚实但非闭合 |

**推荐**: 先做截止能量的最小计算, 如果 N(E_cutoff) 接近 137, 再讨论截止能量的物理来源。
如果无法在 2 周内产出可验证结果 → 标注 D5-020 为 "obstructed", 等待 φ 场理论突破。

## 诚实边界

D5-020 目前无法闭合。α=1/137 在 MSS 中仍是 **conjecture** 而非 **theorem**。
关闭条件: 任一 C1-C4 路径完成可验证推导。
