## WebSocket Usage Example

```python
# Server side
manager = WebSocketManager()
await manager.connect(websocket, "client_1")

# Subscribe to channels
await manager.handle_message("client_1", json.dumps({
    "type": "subscribe",
    "data": {"channels": ["status", "metrics"]}
}))

# Broadcast to channel subscribers
await manager.broadcast_metrics({
    "cpu_percent": 45.2,
    "memory_percent": 62.1
})
```
