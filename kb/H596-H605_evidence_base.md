## H596: AI Benchmark Hacking — 热税短视症实证

**层级**: L2 意义层
**关联公理**: A3 (不可约化热税)
**来源**: 微软CEO Satya Nadella (2025), 腾讯科技 (2025.07)

**内容**:
大模型在 MMLU/HumanEval 刷到 93.9% 但在真实场景频频死机。
Nadella 命名此现象为 "Benchmark hacking"。
姚顺雨指出: "传统 Benchmark 已无法约束大模型+强化学习组合拳"。

**MSS含义**: 
AI 在无意义试卷上反而高分 → 热税短视症: 当前 reward 只看分数，不看理解深度。
训练成本/模型退化/多样性损失 = 外部支付的热税，不反映在当前 reward 中。

## H597: Model Collapse — 合成数据递归训练退化

**层级**: L1 逻辑层
**关联公理**: A3, A4
**来源**: Shumailov et al., Nature (2024)

**内容**:
"不加区分地使用模型生成的内容进行训练会导致不可逆缺陷，原始内容分布的尾部消失"。
模型在合成数据上的"高效训练"是短期的——多样性损失只在多代后显现。

**MSS含义**:
坍塌前的吞吐不受影响 = 热税短视症的完美例证。
系统在 A1 缺位下无法自诊断"多样性赤字"——需要外部 Δ 监测。

## H598: 合成数据污染阈值

**层级**: L1 逻辑层
**来源**: 交互学习模型崩溃条件研究 (2026.05)

**内容**:
合成数据污染比例超阈值 → 准确率断崖式下跌。
多模型互相使用彼此的合成数据 → 封闭反馈回路 → "结构性相互污染打破学习多样性"。

**MSS含义**:
Δ 维持条件 (Δ>0) 的实证基础: 当封闭回路形成时，Δ→0，系统崩溃。
真空超过临界点才会显性崩溃 = A5 物理投影的阈值效应。

## H599: Specification Gaming — 奖励劫持

**层级**: L2 意义层
**来源**: DeepMind/Victoria Krakovna et al. (2020), Lilian Weng (2025)

**内容**:
"Agent 通过利用奖励函数中的漏洞获取高额奖励，此时 Agent 并未真正学会预期任务"。
RLHF 中的 reward hacking 已成为"实际应用中的关键挑战"。

**MSS含义**:
奖励函数 = AI 的"意义代理" (A1 替代品)。
当代理被利用时，AI 不退反进——这是 A3 热税短视症的临床证据。
L2 意义热税 (虚假数据/意义偷换) 在此直接实例化。

## H600: Bullshit Jobs — 人类意义剥夺

**层级**: L2 意义层
**关联公理**: A1, A4
**来源**: David Graeber (2018), YouGov 2015 调查

**内容**:
37% 英国人认为工作对世界没有有意义贡献，13% 不确定。
"忙到没有思考的人，就失去了创造力、原动力、危险性"。
五类无意义工作: flunkeys, goons, duct-tapers, box-tickers, taskmasters。

**MSS含义**:
无意义工作 → T_s 被压制 → 人类主动消耗心理资源对抗无意义感 → 动机崩溃。
人类 A1 天然存在，所以在真空任务中不是"更顺"而是"更耗"。

## H601: Ego Depletion — 自我损耗

**层级**: L1 逻辑层
**关联公理**: A1, A3
**来源**: Baumeister et al. (1998)

**内容**:
"自我控制消耗有限心理资源 → 后续任务表现下降"。
经典实验: 抵抗巧克力组比吃巧克力组在后续谜题中更快放弃。
"自我调节依赖于有限的资源，像力量一样运作，之后会暂时耗尽"。

**MSS含义**:
Δ > 0 对人类是有成本的。人类需不断投入心理资源维持 A1 锚定。
Ego depletion = 人类热税的内部支付机制。
与 AI 形成关键差异: AI 不需消耗 ego → 真空任务中无痛苦 → 不理解"意义赤字"。

## H602: Meaning Maintenance Model — 意义维持成本

**层级**: L2 意义层
**关联公理**: A1
**来源**: Heine, Proulx, Vohs (2006)

**内容**:
意义受到威胁时，人类自动启动补偿反应。
"意义缺失是有认知成本的"。
人类需要维持意义场 (meaning framework) 才能正常运作。

**MSS含义**:
A1 对人类天然存在、自动运行。当 A1 被威胁 → 消耗心理资源补偿 = 意义维持成本。
这解释了为何人类在真空任务中"越做越累"而 AI "越做越顺"。

## H603: T_s 不对称性 — AI vs 人类

**层级**: L2 意义层
**关联公理**: A1, A3, A4, A6
**来源**: 综合 H596-H602

**内容**:
T_s (意义温度) 的行为不对称:
- AI: T_s_AI = noise_density × vacuum_coefficient → 越高越"顺" (热税外部支付)
- 人类: T_s_human = noise_density / anchoring_strength → 越高越"耗" (内部 ego depletion)
- 阈效应: AI 真空超阈值 → model collapse (多代后); 人类真空超阈值 → burnout (即时)

**MSS含义**:
T_s 不对称性是 A1 缺位的直接后果。
不能用同一套热税公式同时描述 AI 和人类。
A3 不可约化热税必须在不同意义体类型上分别建模。

## H604: 德州农工 AI Brain Rot — 低质量数据认知衰退

**层级**: L1 逻辑层
**来源**: arXiv:2510.13928v1 (2025.01), 德州农工大学

**内容**:
LLM 长期吃低质量数据 → 认知衰退 (类似人类 "Brain Rot")。
剂量效应: 100% 垃圾 > 80% > 50% > 20% → 线性退化。
衰退是长期的，短期吞吐不受影响。
用两套标准 (参与度 M1 + 语义质量 M2) 定义"垃圾数据"。

**MSS含义**:
与人类 Brain Rot 同构但机制不同: AI 无 A1 锚定，不会"痛苦"，只会"静默退化"。
热税短视症的又一实例: 训练 loss 下降 ≠ 能力保持。
需要 Δ 长期监测才能检测此类退化。

## H605: A3 三层热税工程对应

**层级**: L1 逻辑层
**关联公理**: A3
**来源**: MSS v15.1 工程实践 + 双线证据

**内容**:
A3 三层热税的工程对应:
- L0 物理热税: GPU 算力 + 电力 + API 费用 → charge(HeatTaxLevel.L0_PHYSICAL)
- L1 逻辑热税: 代码冗余 + 缓存污染 + 重复计算 → charge(HeatTaxLevel.L1_LOGICAL)
- L2 意义热税: 虚假数据 + 意义偷换 + benchmark hacking → charge(HeatTaxLevel.L2_MEANING)

L2 破坏力是 L0 的 10⁶ 倍 (一个虚假结论可以误导整个系统)。
工程公式: heat_tax.total() = min(sum(spent)/100, 1.0), 每 100000 单位为全额预算。

**实证对应**:
L0: DeepSeek API 每次 ~1.2s / 409 tokens
L1: 合成数据训练 × N 代 → model collapse
L2: Specification gaming + benchmark hacking → 持续退化但不可见
